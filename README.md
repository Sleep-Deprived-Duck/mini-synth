Main functions are all on the PCB, screwed into a simple case

Features:

Basic volume and pitch controls using rotary encoders as knobs

Note glide duration and glide speed controls using 2 potentiometers

4 LEDs that can be programmed with various colours as indicators and such

All reprogrammable to preference
